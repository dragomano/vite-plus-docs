# vp pm patch {#vp-pm-patch}

Подготавливает установленную зависимость к локальному патчу.

```bash
vp pm patch my-dependency@1.0.0
```

Измените пакет в расположении, указанном нативным менеджером, затем сохраните патч командой [patch-commit](./patch-commit).

## Параметры {#options}

Требуется спецификация пакета. Дополнительных параметров Vite+ нет.

Параметров, специфичных для команды, нет.

## Совместимость {#compatibility}

- **npm:** 12 или новее: `npm patch add`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **pnpm:** 7.4 или новее: `pnpm patch`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Yarn Classic:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Yarn Modern:** `yarn patch`.
- **Bun:** `bun patch`.

Расположение изменяемых файлов и формат хранения патча — детали нативного менеджера. Vite+ не преобразует патчи между менеджерами.

## Нативные параметры {#native-options}

Список нативных параметров: [npm patch add](https://docs.npmjs.com/cli/v12/commands/npm-patch), [pnpm patch](https://pnpm.io/cli/patch), [Yarn patch](https://yarnpkg.com/cli/patch) и [Bun patch](https://bun.com/docs/pm/cli/patch). Чтобы передать эти параметры через Vite+, см. [Нативные аргументы](./#native-arguments).
