# vp add {#vp-add}

Добавляет пакеты в проект и обновляет его манифест и lock-файл.

```bash
vp add react
vp add -D typescript
vp add --save-peer react
vp add --filter web react
```

## Параметры {#options}

Одновременно выбирается только один целевой раздел зависимостей. Peer-зависимости следуют поведению нативного менеджера, включая то, записывает ли менеджер также зависимость для разработки.

| Параметр                     | Описание                                                      | Примечания                                                                                     |
| ---------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `-P, --save-prod`            | Сохраняет в dependencies — целевой раздел по умолчанию.       | Один целевой раздел зависимостей.                                                              |
| `-D, --save-dev`             | Сохраняет в devDependencies.                                  | Один целевой раздел зависимостей.                                                              |
| `--save-peer`                | Запрашивает поведение сохранения peer-зависимостей менеджера. | Один целевой раздел зависимостей.                                                              |
| `-O, --save-optional`        | Сохраняет в optionalDependencies.                             | Один целевой раздел зависимостей.                                                              |
| `-E, --save-exact`           | Сохраняет точную версию зависимости.                          |                                                                                                |
| `--save-catalog-name <name>` | Сохраняет зависимость в именованный каталог.                  |                                                                                                |
| `--save-catalog`             | Сохраняет зависимость в каталог по умолчанию.                 |                                                                                                |
| `--allow-build <names>`      | Разрешает указанным пакетам выполнять сценарии postinstall.   |                                                                                                |
| `--ignore-scripts`           | Не выполняет сценарии жизненного цикла.                       |                                                                                                |
| `--no-optional`              | Не устанавливает optionalDependencies.                        | Нельзя использовать вместе с `--global`.                                                       |
| `--frozen-lockfile`          | Запрещает изменения lock-файла.                               | Нельзя использовать вместе с `--global`. Переопределяет ранее заданный `--no-frozen-lockfile`. |
| `--no-frozen-lockfile`       | Явно разрешает обновление lock-файла.                         | Нельзя использовать вместе с `--global`. Переопределяет ранее заданный `--frozen-lockfile`.    |
| `--lockfile-only`            | Обновляет lock-файл без полной установки.                     | Нельзя использовать вместе с `--global`.                                                       |
| `--prefer-offline`           | Использует кэшированные пакеты, если они доступны.            | Нельзя использовать вместе с `--global`.                                                       |
| `--offline`                  | Использует только пакеты, уже находящиеся в кэше.             | Нельзя использовать вместе с `--global`.                                                       |
| `-f, --force`                | Запрашивает принудительную переустановку.                     | Нельзя использовать вместе с `--global`.                                                       |
| `--no-lockfile`              | Пропускает чтение и создание lock-файла.                      | Нельзя использовать вместе с `--global`.                                                       |
| `--shamefully-hoist`         | Создаёт плоскую структуру node_modules.                       | Нельзя использовать вместе с `--global`.                                                       |
| `--silent`                   | Подавляет вывод Vite+ и запрашивает нативный тихий вывод.     | Нельзя использовать вместе с `--global`.                                                       |
| `--filter <pattern>`         | Выбирает рабочие пространства по шаблону.                     | Можно указывать несколько раз.                                                                 |
| `-w, --workspace-root`       | Добавляет в корень рабочего пространства.                     |                                                                                                |
| `--workspace`                | Требует наличие зависимости в рабочем пространстве.           |                                                                                                |
| `-g, --global`               | Устанавливает глобально.                                      | Требуется глобальный CLI. Используется [глобальное хранилище пакетов](./global-packages).      |
| `--node <version>`           | Версия Node.js для глобальной установки.                      | Требуется `--global`.                                                                          |
| `--concurrency <number>`     | Количество параллельных установок глобальных пакетов.         | Требуется `--global`. Значение должно быть положительным целым числом.                         |

## Совместимость {#compatibility}

Приведённые ниже команды описывают операции над проектом. Глобальный режим описан в разделе [Параметры](#options).

- **npm:** `npm install`.
- **pnpm:** `pnpm add`.
- **Yarn Classic:** `yarn add`.
- **Yarn Modern:** `yarn add`.
- **Bun:** `bun add`.

| Параметр                     | npm              | pnpm              | Yarn Classic | Yarn Modern | Bun             | Примечания                                             |
| ---------------------------- | ---------------- | ----------------- | ------------ | ----------- | --------------- | ------------------------------------------------------ |
| `-P, --save-prod`            | Да               | Да                | Да           | Да          | Да              | Yarn и Bun сохраняют существующую запись.              |

| `-E, --save-exact`           | Да               | Да                | Да           | Да          | Да              |                                                        |
| `--save-catalog-name <name>` | Нет              | 10.12.0 или новее | Нет          | Нет         | 1.4 или новее   |                                                        |
| `--save-catalog`             | Нет              | 10.12.0 или новее | Нет          | Нет         | 1.4 или новее   |                                                        |
