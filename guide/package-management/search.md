# vp pm search {#vp-pm-search}

Ищет в реестре пакетов.

```bash
vp pm search vite plugin
vp pm search typescript --json
```

## Параметры {#options}

Требуется хотя бы один поисковый термин.

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--long`           | Показывает расширенную информацию.         |                                 |
| `--registry <url>` | Выбор реестра.                             |                                 |

## Совместимость {#compatibility}

- **npm:** `npm search`.
- **pnpm:** 11 или новее: `pnpm search`. Более ранние версии используют `npm search` как запасной вариант.
- **Yarn Classic:** Запасной вариант: `npm search`.
- **Yarn Modern:** Запасной вариант: `npm search`.
- **Bun:** Запасной вариант: `npm search`.

| Параметр           | npm | pnpm  | Yarn Classic | Yarn Modern | Bun | Примечания |
| ------------------ | --- | ----- | ------------ | ----------- | --- | ---------- |
| `--json`           | Да  | Да    | Да           | Да          | Да  |            |
| `--long`           | Да  | До 11 | Да           | Да          | Да  |            |
| `--registry <url>` | Да  | Да    | Да           | Да          | Да  |            |

Настройки реестра и вывод соответствуют выполняемой команде.
