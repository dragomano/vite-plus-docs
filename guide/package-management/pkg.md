# vp pm pkg {#vp-pm-pkg}

Читает и обновляет поля `package.json` без ручного редактирования манифеста.

```bash
vp pm pkg get name version
vp pm pkg set scripts.check='vp check'
vp pm pkg set private=true --json
vp pm pkg delete scripts.old
vp pm pkg fix
```

## Параметры {#options}

- `get [key...]` читает поля или весь манифест, если ключи не указаны. `--json` запрашивает нативный вывод в формате JSON.
- `set <key=value...>` записывает поля. `--json` разбирает значения как JSON, поэтому логические значения, числа, массивы и объекты не сохраняются как строки.
- `delete <key...>` удаляет поля.
- `fix` просит менеджер исправить распространённые ошибки манифеста.

Пути к полям и нормализация соответствуют нативному менеджеру. Пути, содержащие квадратные скобки или символы, значимые для оболочки, заключайте в кавычки.

### `get` {#get}

| Параметр | Описание              | Примечания                      |
| -------- | --------------------- | ------------------------------- |
| `--json` | Вывод в формате JSON. | Вывод сохраняет нативную схему. |

### `set` {#set}

| Параметр | Описание                                   | Примечания                                                                      |
| -------- | ------------------------------------------ | ------------------------------------------------------------------------------- |
| `--json` | Разбирает значения как JSON перед записью. | Разбирает логические значения, числа, массивы и объекты, а не сохраняет строки. |

### `delete` {#delete}

У подкоманды нет собственных параметров.

### `fix` {#fix}

У подкоманды нет собственных параметров.

## Совместимость {#compatibility}

### `get` {#get-1}

- **npm:** 7.20.0 или новее: `npm pkg get`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **pnpm:** 11.3.0 или новее: `pnpm pkg get`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Yarn Classic:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** 1.2.19 или новее: `bun pm pkg get`. Более ранние версии выводят предупреждение и пропускают выполнение.
