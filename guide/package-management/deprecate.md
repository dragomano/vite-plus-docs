# vp pm deprecate {#vp-pm-deprecate}

Задаёт сообщение об устаревании для опубликованной версии пакета или диапазона версий.

```bash
vp pm deprecate 'my-package@<2.0.0' 'Upgrade to version 2 or later'
```

## Параметры {#options}

Требуются спецификация пакета и сообщение.

Устаревание предупреждает пользователей; оно не удаляет пакет из реестра.

| Параметр           | Описание                     | Примечания |
| ------------------ | ---------------------------- | ---------- |
| `--otp <otp>`      | Передаёт одноразовый пароль. |            |
| `--registry <url>` | Выбор реестра.               |            |

## Совместимость {#compatibility}

- **npm:** `npm deprecate`.
- **pnpm:** 11 или новее: `pnpm deprecate`. Более ранние версии используют `npm deprecate` как запасной вариант.
- **Yarn Classic:** Запасной вариант: `npm deprecate`.
- **Yarn Modern:** Запасной вариант: `npm deprecate`.
- **Bun:** Запасной вариант: `npm deprecate`.

| Параметр           | npm | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания |
| ------------------ | --- | ---- | ------------ | ----------- | --- | ---------- |
| `--otp <otp>`      | Да  | Да   | Да           | Да          | Да  |            |
| `--registry <url>` | Да  | Да   | Да           | Да          | Да  |            |

Bun выводит предупреждение о запасном варианте. Конфигурация реестра и аутентификация определяются выполняемой командой.

Пустое сообщение передаётся без изменений. Нативный pnpm отклоняет его; Vite+ не преобразует его в `undeprecate`.
