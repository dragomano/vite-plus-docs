# vp pm team {#vp-pm-team}

Управление командами организации в реестре и их составом.

```bash
vp pm team list my-org
vp pm team list my-org:developers --json
vp pm team create my-org:developers
vp pm team add my-org:developers alice
vp pm team rm my-org:developers alice
vp pm team destroy my-org:developers
```

## Параметры {#options}

- `create <scope:team>` создаёт команду.
- `destroy <scope:team>` удаляет команду.
- `add <scope:team> <user>` добавляет участника.
- `rm <scope:team> <user>` удаляет участника. Псевдоним: `remove`.
- `list <scope[:team]>` выводит список команд организации или участников команды. Псевдоним: `ls`.

Все подкоманды принимают `--registry <url>`, `--otp <code>` и `--json`. Вывод в формате JSON сохраняет нативную схему менеджера. Разрешения в реестре определяют, какие изменения может вносить аутентифицированная учётная запись.

### `create` {#create}

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--otp <otp>`      | Передаёт одноразовый пароль.               |                                 |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--registry <url>` | Выбор реестра.                             |                                 |

## Совместимость {#compatibility}

Запасные варианты, использующие npm, выводят предупреждения.

### `create` {#create-1}

- **npm:** `npm team create`.
- **pnpm:** 11.13.0 или новее: `pnpm team create`. Более ранние версии используют `npm team create` как запасной вариант.
- **Yarn Classic:** `yarn team create`.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** Запасной вариант: `npm team create`.

| Параметр           | npm | pnpm | Yarn Classic     | Yarn Modern | Bun | Примечания                                                                                                 |
| ------------------ | --- | ---- | ---------------- | ----------- | --- | ---------------------------------------------------------------------------------------------------------- |
| `--otp <otp>`      | Да  | Да   | 1.12.1 или новее | Нет         | Да  | Более старые версии Yarn Classic могут игнорировать `--otp`. Vite+ не проверяет здесь версию Yarn Classic. |
| `--json`           | Да  | Да   | Да               | Нет         | Да  |                                                                                                            |
| `--registry <url>` | Да  | Да   | Да               | Нет         | Да  |                                                                                                            |
