# vp pm token {#vp-pm-token}

Управление токенами аутентификации в реестре.

```bash
vp pm token list
vp pm token list --json
vp pm token revoke <token-id>
```

## Параметры {#options}

- `list`, также записывается как `ls`, выводит список токенов. Поддерживает `--json` и `--registry <url>`.
- `create` запрашивает новый токен. Поддерживает `--json`, `--registry <url>`, `--readonly` и повторяемые ограничения `--cidr <range>`.
- `revoke <token-or-id>` отзывает токен. Поддерживает `--registry <url>`.

Считайте токены секретами. Для отзыва предпочтительнее использовать идентификатор токена, а не помещать сам токен в историю оболочки. Создание токенов и поддерживаемые типы токенов зависят от текущей политики реестра и версии нативного менеджера пакетов; наличие команды `create` не гарантирует, что реестр разрешает создание токенов из CLI.

### `list` {#list}

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--registry <url>` | Выбор реестра.                             |                                 |

### `create` {#create}

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--registry <url>` | Выбор реестра.                             |                                 |
| `--cidr <cidr>`    | Диапазоны CIDR для ограничения токена.     | Может повторяться.              |
| `--readonly`       | Создаёт токен только для чтения.           |                                 |

### `revoke` {#revoke}

| Параметр           | Описание       | Примечания |
| ------------------ | -------------- | ---------- |
| `--registry <url>` | Выбор реестра. |            |

## Совместимость {#compatibility}

### `list` {#list-1}

- **npm:** `npm token list`.
- **pnpm:** 12.13 или новее: `pnpm token list`. Более ранние версии используют `npm token list` как запасной вариант.
- **Yarn Classic:** Запасной вариант: `npm token list`.
- **Yarn Modern:** Запасной вариант: `npm token list`.
- **Bun:** Запасной вариант: `npm token list`.

| Параметр           | npm | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания |
| ------------------ | --- | ---- | ------------ | ----------- | --- | ---------- |
| `--json`           | Да  | Да   | Да           | Да          | Да  |            |
| `--registry <url>` | Да  | Да   | Да           | Да          | Да  |            |

### `create` {#create-1}

- **npm:** `npm token create`.
- **pnpm:** 12.13 или новее: `pnpm token create`. Более ранние версии используют `npm token create` как запасной вариант.
- **Yarn Classic:** Запасной вариант: `npm token create`.
- **Yarn Modern:** Запасной вариант: `npm token create`.
- **Bun:** Запасной вариант: `npm token create`.

| Параметр           | npm | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания |
| ------------------ | --- | ---- | ------------ | ----------- | --- | ---------- |
| `--json`           | Да  | Да   | Да           | Да          | Да  |            |
| `--registry <url>` | Да  | Да   | Да           | Да          | Да  |            |
| `--cidr <cidr>`    | Да  | Да   | Да           | Да          | Да  |            |
| `--readonly`       | Да  | Да   | Да           | Да          | Да  |            |

### `revoke` {#revoke-1}

- **npm:** `npm token revoke`.
- **pnpm:** 12.13 или новее: `pnpm token revoke`. Более ранние версии используют `npm token revoke` как запасной вариант.
- **Yarn Classic:** Запасной вариант: `npm token revoke`.
- **Yarn Modern:** Запасной вариант: `npm token revoke`.
- **Bun:** Запасной вариант: `npm token revoke`.

| Параметр           | npm | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания |
| ------------------ | --- | ---- | ------------ | ----------- | --- | ---------- |
| `--registry <url>` | Да  | Да   | Да           | Да          | Да  |            |

Команда `revoke` принимает один токен или идентификатор. Аутентификация, запросы пароля и разрешение токенов выполняются нативной командой. Vite+ не нормализует типы токенов и схемы вывода.
