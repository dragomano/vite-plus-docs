# vp pm stage {#vp-pm-stage}

Поэтапная публикация отделяет загрузку пакета от его выпуска. Задача CI может загрузить поэтапную версию без 2FA, а затем сопровождающий одобрит или отклонит её с доверенного устройства с 2FA.

```bash
vp pm stage publish --dry-run
vp pm stage publish
vp pm stage list
vp pm stage view <stage-id>
vp pm stage download <stage-id>
vp pm stage approve <stage-id>
vp pm stage reject <stage-id>
```

## Параметры {#options}

Используйте приведённые ниже подкоманды, чтобы загрузить поэтапные версии, просмотреть их, одобрить или отклонить.

### `publish` {#publish}

Загружает пакет. Принимает необязательную цель в виде tarball-архива или папки.

| Параметр                        | Описание                                                       | Примечания                            |
| ------------------------------- | -------------------------------------------------------------- | ------------------------------------- |
| `--tag <tag>`                   | Тег публикации.                                                |                                       |
| `--access <public\|restricted>` | Запрашивает публичный или ограниченный доступ к пакету.        |                                       |
| `--otp <otp>`                   | Передаёт одноразовый пароль.                                   |                                       |
| `--dry-run`                     | Предпросмотр без поэтапной публикации.                         |                                       |
| `--json`                        | Запрашивает нативный вывод в формате JSON.                     | Вывод сохраняет нативную схему.       |
| `-r, --recursive`               | Поэтапно публикует все публикуемые пакеты рабочих пространств. |                                       |
| `--filter <pattern>`            | Выбирает рабочие пространства по шаблону.                      | Можно повторять.                      |
| `--provenance`                  | Публикует поэтапно с атрибуцией происхождения (provenance).    | Требует совместимой среды публикации. |
| `--registry <url>`              | Выбор реестра.                                                 |                                       |

### `list` {#list}

Выводит поэтапные версии. Принимает необязательную спецификацию пакета. Псевдоним: `ls`.

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--registry <url>` | Выбор реестра.                             |                                 |

### `view` {#view}

Показывает сведения о поэтапной версии. Требует идентификатор поэтапной версии.

| Параметр           | Описание                                   | Примечания                      |
| ------------------ | ------------------------------------------ | ------------------------------- |
| `--json`           | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |
| `--registry <url>` | Выбор реестра.                             |                                 |

### `download` {#download}

Загружает поэтапный tarball-архив. Требует идентификатор поэтапной версии.

| Параметр           | Описание       | Примечания |
| ------------------ | -------------- | ---------- |
| `--registry <url>` | Выбор реестра. |            |

### `approve` {#approve}

Переводит поэтапную версию в основной реестр. Требует идентификатор поэтапной версии.

| Параметр           | Описание                     | Примечания |
| ------------------ | ---------------------------- | ---------- |
| `--otp <otp>`      | Передаёт одноразовый пароль. |            |
| `--registry <url>` | Выбор реестра.               |            |

### `reject` {#reject}

Отклоняет поэтапную версию. Требует идентификатор поэтапной версии.

| Параметр           | Описание                     | Примечания |
| ------------------ | ---------------------------- | ---------- |
| `--otp <otp>`      | Передаёт одноразовый пароль. |            |
| `--registry <url>` | Выбор реестра.               |            |

## Совместимость {#compatibility}

Все пути npm, включая запасные варианты, требуют npm 11.15 или новее и Node.js 22.14 или новее.

### `publish` {#publish-1}

- **npm:** 11.15 или новее: `npm stage publish`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **pnpm:** 11.3 или новее: `pnpm stage publish`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Yarn Classic:** Запасной вариант: `npm stage publish`.
- **Yarn Modern:** 4.16.0 или новее: `yarn npm publish --staged`. Более ранние версии используют `npm stage publish` как запасной вариант. Явные цели используют запасной вариант npm.
- **Bun:** Запасной вариант: `npm stage publish`.

| Параметр                        | npm                   | pnpm | Yarn Classic          | Yarn Modern                   | Bun                   | Примечания                              |
| ------------------------------- | --------------------- | ---- | --------------------- | ----------------------------- | --------------------- | --------------------------------------- |
| `--tag <tag>`                   | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `--access <public\|restricted>` | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `--otp <otp>`                   | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `--dry-run`                     | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `--json`                        | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `-r, --recursive`               | Нет цели или цель `.` | Да   | Нет цели или цель `.` | До 4.16 без цели или цель `.` | Нет цели или цель `.` |                                         |
| `--filter <pattern>`            | Нет цели или цель `.` | Да   | Нет цели или цель `.` | До 4.16 без цели или цель `.` | Нет цели или цель `.` |                                         |
| `--provenance`                  | Да                    | Да   | Да                    | Да                            | Да                    |                                         |
| `--registry <url>`              | Да                    | Да   | Да                    | До 4.16 или явная цель        | Да                    | Реестр настраивается в настройках Yarn. |
