# vp install {#vp-install}

Устанавливает зависимости, объявленные проектом. Псевдоним: `vp i`. Указание имён пакетов переключает команду на поведение [add](./add).

```bash
vp install
vp install --frozen-lockfile
vp install --lockfile-only
vp install --filter web
vp install react
```

## Параметры {#options}

| Параметр                 | Описание                                                                                | Примечания                                                                                                         |
| ------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `-P, --prod`             | Выбирает продакшен-зависимости или сохраняет добавленные пакеты в dependencies.         |                                                                                                                    |
| `-D, --dev`              | Включает зависимости для разработки или сохраняет добавленные пакеты в devDependencies. |                                                                                                                    |
| `--no-optional`          | Не устанавливает optionalDependencies.                                                  |                                                                                                                    |
| `--frozen-lockfile`      | Запрещает изменения lock-файла.                                                         | Переопределяет ранее заданный `--no-frozen-lockfile`.                                                              |
| `--no-frozen-lockfile`   | Явно разрешает обновление lock-файла.                                                   | Переопределяет ранее заданный `--frozen-lockfile`.                                                                 |
| `--lockfile-only`        | Обновляет lock-файл без полной установки.                                               |                                                                                                                    |
| `--prefer-offline`       | Использует кэшированные пакеты, если они доступны.                                      |                                                                                                                    |
| `--offline`              | Использует только пакеты, уже находящиеся в кэше.                                       |                                                                                                                    |
| `-f, --force`            | Запрашивает принудительную переустановку.                                               |                                                                                                                    |
| `--ignore-scripts`       | Не выполняет сценарии жизненного цикла.                                                 |                                                                                                                    |
| `--no-lockfile`          | Пропускает чтение и создание lock-файла.                                                |                                                                                                                    |
| `--fix-lockfile`         | Восстанавливает записи lock-файла.                                                      | Нельзя использовать вместе с именами пакетов.                                                                      |
| `--shamefully-hoist`     | Создаёт плоскую структуру node_modules.                                                 |                                                                                                                    |
| `--resolution-only`      | Повторно выполняет разрешение зависимостей для анализа.                                 | Нельзя использовать вместе с именами пакетов.                                                                      |
| `--silent`               | Подавляет вывод Vite+ и запрашивает нативный тихий вывод.                               |                                                                                                                    |
| `--filter <pattern>`     | Выбирает рабочие пространства по шаблону.                                               | Можно указывать несколько раз.                                                                                     |
| `-w, --workspace-root`   | Выбирает корень рабочего пространства.                                                  |                                                                                                                    |
| `-E, --save-exact`       | Сохраняет точную версию зависимости.                                                    | Требуются имена пакетов.                                                                                           |
| `--save-peer`            | Запрашивает поведение сохранения peer-зависимостей менеджера.                           | Требуются имена пакетов.                                                                                           |
| `-O, --save-optional`    | Сохраняет в optionalDependencies.                                                       | Требуются имена пакетов.                                                                                           |
| `--save-catalog`         | Сохраняет зависимость в каталог по умолчанию.                                           | Требуются имена пакетов.                                                                                           |
| `-g, --global`           | Устанавливает глобально.                                                                | Требуется глобальный CLI. Используется [глобальное хранилище пакетов](./global-packages). Требуются имена пакетов. |
| `--node <version>`       | Версия Node.js для глобальной установки.                                                | Требуется `--global`.                                                                                              |
| `--concurrency <number>` | Количество параллельных установок глобальных пакетов.                                   | Требуется `--global`. Значение должно быть положительным целым числом.                                             |

## Совместимость {#compatibility}

Приведённые ниже команды описывают операции над проектом. Глобальный режим описан в разделе [Параметры](#options).

- **npm:** `npm install`, или `npm ci` с `--frozen-lockfile` и без имён пакетов. С именами пакетов: `npm install`.
- **pnpm:** `pnpm install`. С именами пакетов: `pnpm add`.
- **Yarn Classic:** `yarn install`. С именами пакетов: `yarn add`.
- **Yarn Modern:** `yarn install`. С именами пакетов: `yarn add`.
- **Bun:** `bun install`. С именами пакетов: `bun add`.

### Git- и удалённые tarball-зависимости {#git-and-remote-tarball-dependencies}

npm 12 по умолчанию отключает git-зависимости и удалённые tarball-URL. Установка может завершиться ошибкой `EALLOWGIT` или `EALLOWREMOTE`. Включайте эти источники через проектную конфигурацию npm `allow-git` или `allow-remote` только тогда, когда они действительно нужны.

Для подтверждения сценариев сборки зависимостей см. [approve-builds](./approve-builds).
