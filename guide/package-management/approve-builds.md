# vp pm approve-builds {#vp-pm-approve-builds}

Одобряет сценарии жизненного цикла зависимостей по политике доверия выбранного менеджера. Одобряются только те пакеты, сценарии установки которых предполагается выполнять.

```bash
vp pm approve-builds
vp pm approve-builds sharp
vp pm approve-builds '!untrusted-package'
vp pm approve-builds --all
```

## Параметры {#options}

Укажите пакеты для одобрения или добавьте к имени префикс `!`, чтобы запросить запрет там, где это поддерживается. Заключайте аргументы запрета в кавычки, чтобы избежать раскрытия истории оболочки.

| Параметр | Описание                                                  | Примечания                                                              |
| -------- | --------------------------------------------------------- | ----------------------------------------------------------------------- |
| `--all`  | Одобряет все пакеты, ожидающие одобрения сценария сборки. | Нельзя использовать вместе с именами пакетов, включая имена после `--`. |

## Совместимость {#compatibility}

- **npm:** 11.16 или новее: `npm approve-scripts`. Более ранние версии выводят предупреждение и пропускают выполнение. Для запретов используется `npm deny-scripts`.
- **pnpm:** 10.1 или новее: `pnpm approve-builds`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Yarn Classic:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** `bun pm trust` для указанных пакетов или `--all`.

| Параметр | npm               | pnpm              | Yarn Classic | Yarn Modern | Bun | Примечания |
| -------- | ----------------- | ----------------- | ------------ | ----------- | --- | ---------- |
| `--all`  | 11.16.0 или новее | 10.32.0 или новее | Нет          | Нет         | Да  |            |

Без имён пакетов pnpm открывает интерактивный сценарий, а npm выводит список ожидающих пакетов с `--allow-scripts-pending`. Bun не открывает интерактивный выбор: ожидающие пакеты можно посмотреть с помощью `bun pm untrusted`, а затем указать имена пакетов, которым требуется доверие.

Аргументы запрета с префиксом `!` требуют pnpm 11 или новее либо npm 11.16 или новее. npm требует отдельных запусков для одобрения и для запрета. Bun пропускает записи запрета с предупреждением, поскольку использует `trustedDependencies` вместо списка запретов.

Для Yarn Modern настройте `enableScripts: false` и явно разрешите доверенные пакеты через `dependenciesMeta`.

### Политика сценариев сборки в npm {#npm-build-script-policy}

npm 12 применяет `allowScripts` из `package.json`. Сценарии установки зависимостей, не охваченные политикой, пропускаются, включая неявные нативные сборки. Одобрение обновляет политику, но не выполняет ранее пропущенные сценарии. Далее выполните [`vp pm rebuild <package>`](./rebuild).

В npm 11.16 и более поздних версиях 11.x эта политика носит рекомендательный характер. Сценарии всё равно выполняются, а npm предупреждает о непроверенных пакетах.
