# vp pm owner {#vp-pm-owner}

Управление владельцами пакетов. Псевдоним: `vp pm author`.

```bash
vp pm owner list my-package
vp pm owner add alice my-package
vp pm owner rm alice my-package
```

## Параметры {#options}

- `list <package>` выводит список владельцев. Псевдоним: `ls`.
- `add <user> <package>` выдаёт права владения.
- `rm <user> <package>` снимает права владения.

Каждая подкоманда принимает `--otp <code>`. Эти подкоманды не принимают дополнительные нативные аргументы после `--`. Изменения прав владения затрагивают разрешения в реестре, а не поле `author` локального манифеста.

### `list` {#list}

| Параметр      | Описание                     | Примечания |
| ------------- | ---------------------------- | ---------- |
| `--otp <otp>` | Передаёт одноразовый пароль. |            |

| Параметр      | Описание                     | Примечания |

## Совместимость {#compatibility}

### `list` {#list-1}

- **npm:** `npm owner list`.
- **pnpm:** 11.1 или новее: `pnpm owner list`. Более ранние версии используют `npm owner list` как запасной вариант.
- **Yarn Classic:** `yarn owner list`.
- **Yarn Modern:** Запасной вариант: `npm owner list`.
- **Bun:** Запасной вариант: `npm owner list`.

| Параметр      | npm | pnpm | Yarn Classic     | Yarn Modern | Bun | Примечания |
| ------------- | --- | ---- | ---------------- | ----------- | --- | ---------- |
| `--otp <otp>` | Да  | Да   | 1.12.1 или новее | Да          | Да  |            |

### `add` {#add-1}

- **npm:** `npm owner add`.
- **pnpm:** 11.1 или новее: `pnpm owner add`. Более ранние версии используют `npm owner add` как запасной вариант. Нативный pnpm указывает пакет перед пользователем.
- **Yarn Classic:** `yarn owner add`. Указывает пользователя перед пакетом.
- **Yarn Modern:** Запасной вариант: `npm owner add`.
- **Bun:** Запасной вариант: `npm owner add`.

| Параметр      | npm | pnpm | Yarn Classic     | Yarn Modern | Bun | Примечания |
| ------------- | --- | ---- | ---------------- | ----------- | --- | ---------- |
| `--otp <otp>` | Да  | Да   | 1.12.1 или новее | Да          | Да  |            |

### `rm` {#rm-1}

- **npm:** `npm owner rm`.
- **pnpm:** 11.1 или новее: `pnpm owner rm`. Более ранние версии используют `npm owner rm` как запасной вариант. Нативный pnpm указывает пакет перед пользователем.
- **Yarn Classic:** `yarn owner remove`. Указывает пользователя перед пакетом. Удаление может завершиться ошибкой в Yarn Classic 1.22.22 из-за ошибки в исходном коде Yarn Classic. Vite+ не повторяет операцию через npm.
- **Yarn Modern:** Запасной вариант: `npm owner rm`.
- **Bun:** Запасной вариант: `npm owner rm`.

| Параметр      | npm | pnpm | Yarn Classic     | Yarn Modern | Bun | Примечания |
| ------------- | --- | ---- | ---------------- | ----------- | --- | ---------- |
| `--otp <otp>` | Да  | Да   | 1.12.1 или новее | Да          | Да  |            |

Учётные данные и авторизация в реестре определяются выполняемой командой.

## Нативные параметры {#native-options}

Требования к реестру и нативные параметры приведены в [npm owner](https://docs.npmjs.com/cli/v11/commands/npm-owner), [pnpm owner](https://pnpm.io/cli/owner) и [Yarn Classic owner](https://classic.yarnpkg.com/en/docs/cli/owner). Параметры, не перечисленные выше, необходимо использовать непосредственно с нативной командой.
