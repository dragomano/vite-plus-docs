# vp list {#vp-list}

Выводит список установленных зависимостей. Псевдоним: `vp ls`. Эти команды верхнего уровня требуют глобального CLI. И глобальный CLI, и локальный CLI проекта принимают `vp pm list` и `vp pm ls`.

```bash
vp list
vp list react --depth 2
vp list --json
vp list -g
```

## Параметры {#options}

| Параметр                  | Описание                                      | Примечания                                                                                |
| ------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `--depth <depth>`         | Максимальная глубина дерева зависимостей.     |                                                                                           |
| `--json`                  | Запрашивает нативный вывод в формате JSON.    | Вывод сохраняет нативную схему.                                                           |
| `--long`                  | Показывает расширенную информацию.            |                                                                                           |
| `--parseable`             | Разбираемый формат вывода.                    |                                                                                           |
| `-P, --prod`              | Только продакшен-зависимости.                 |                                                                                           |
| `-D, --dev`               | Включает зависимости для разработки.          |                                                                                           |
| `--no-optional`           | Исключает optional-зависимости.               |                                                                                           |
| `--exclude-peers`         | Исключает peer-зависимости.                   |                                                                                           |
| `--only-projects`         | Показывает только пакеты проекта.             |                                                                                           |
| `--find-by <finder_name>` | Использует функцию поиска.                    |                                                                                           |
| `-r, --recursive`         | Выводит список по всем рабочим пространствам. |                                                                                           |
| `--filter <pattern>`      | Выбирает рабочие пространства по шаблону.     | Можно указывать несколько раз.                                                            |
| `-g, --global`            | Выводит список глобальных пакетов.            | Требуется глобальный CLI. Используется [глобальное хранилище пакетов](./global-packages). |

## Совместимость {#compatibility}

Приведённые ниже команды описывают операции над проектом. Глобальный режим описан в разделе [Параметры](#options).

- **npm:** `npm list`.
- **pnpm:** `pnpm list`.
- **Yarn Classic:** `yarn list`.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** `bun pm ls`.

| Параметр                  | npm              | pnpm              | Yarn Classic | Yarn Modern | Bun | Примечания                                                                 |
| ------------------------- | ---------------- | ----------------- | ------------ | ----------- | --- | -------------------------------------------------------------------------- |
| `--depth <depth>`         | Да               | Да                | Да           | Нет         | Нет |                                                                            |
| `--json`                  | Да               | Да                | Да           | Нет         | Нет |                                                                            |
| `--long`                  | Да               | Да                | Нет          | Нет         | Нет |                                                                            |
| `--parseable`             | Да               | Да                | Нет          | Нет         | Нет |                                                                            |
| `-P, --prod`              | Да               | Да                | Да           | Нет         | Нет | npm 6 использует `--production`, который также исключает peer-зависимости. |
| `-D, --dev`               | Да               | Да                | Да           | Нет         | Нет |                                                                            |
| `--no-optional`           | 7 или новее      | Да                | Нет          | Нет         | Нет |                                                                            |
| `--exclude-peers`         | 7 или новее      | Да                | Нет          | Нет         | Нет |                                                                            |
| `--only-projects`         | Нет              | Да                | Нет          | Нет         | Нет |                                                                            |
| `--find-by <finder_name>` | Нет              | 10.16.0 или новее | Нет          | Нет         | Нет |                                                                            |
| `-r, --recursive`         | 7.14.0 или новее | Да                | Нет          | Нет         | Нет |                                                                            |
| `--filter <pattern>`      | 7.14.0 или новее | Да                | Нет          | Нет         | Нет |                                                                            |
| `-g, --global`            | Да               | Да                | Да           | Да          | Да  |                                                                            |

Эти результаты описывают установленные пакеты, а не инструменты, поставляемые Vite+ в комплекте. Чтобы посмотреть версии встроенных инструментов Vite, Rolldown, Oxc и других, используйте `vp toolchain [tool]`.
