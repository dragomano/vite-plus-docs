# vp unlink {#vp-unlink}

Удаляет нативные ссылки менеджера пакетов, созданные для локальной разработки.

```bash
vp unlink my-library
```

## Параметры {#options}

Необязательное имя пакета или каталог передаётся менеджеру. `-r, --recursive` запрашивает удаление связей во всех рабочих пространствах, где это поддерживается.

| Параметр          | Описание                                             | Примечания |
| ----------------- | ---------------------------------------------------- | ---------- |
| `-r, --recursive` | Удаляет связи в каждом пакете рабочего пространства. |            |

## Совместимость {#compatibility}

- **npm:** `npm unlink`.
- **pnpm:** `pnpm unlink`.
- **Yarn Classic:** `yarn unlink`.
- **Yarn Modern:** 3 или новее: `yarn unlink`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Bun:** `bun unlink`.

| Параметр          | npm             | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания                                           |
| ----------------- | --------------- | ---- | ------------ | ----------- | --- | ---------------------------------------------------- |
| `-r, --recursive` | 8.1.0 или новее | Да   | Нет          | 3 или новее | Нет | npm включает корень рабочего пространства.           |

Поведение операнда и обновления манифеста определяется нативным менеджером. Команда не удаляет пакеты из [глобального хранилища](./global-packages) Vite+.
