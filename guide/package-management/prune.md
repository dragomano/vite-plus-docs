# vp pm prune {#vp-pm-prune}

Удаляет ненужные установленные пакеты.

```bash
vp pm prune
vp pm prune --prod
```

## Параметры {#options}

| Параметр        | Описание                                                   | Примечания |
| --------------- | ---------------------------------------------------------- | ---------- |
| `--prod`        | Удаляет зависимости для разработки (devDependencies).      |            |
| `--no-optional` | Удаляет необязательные зависимости (optionalDependencies). |            |

## Совместимость {#compatibility}

- **npm:** `npm prune`.
- **pnpm:** `pnpm prune`.
- **Yarn Classic:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** 1.4 или новее: `bun prune`. Более ранние версии выводят предупреждение и пропускают выполнение.

| Параметр        | npm         | pnpm | Yarn Classic | Yarn Modern | Bun           | Примечания |
| --------------- | ----------- | ---- | ------------ | ----------- | ------------- | ---------- |
| `--prod`        | Да          | Да   | Нет          | Нет         | 1.4 или новее |            |
| `--no-optional` | 7 или новее | Да   | Нет          | Нет         | 1.4 или новее |            |

npm 7 и новее переводят флаги выбора в `--omit=dev` и `--omit=optional`. npm 6 переводит `--prod` в `--production` и не поддерживает `--no-optional`. Bun переводит `--prod` в `--production`. Yarn и более ранние версии Bun удаляют лишние пакеты во время установки вместо предоставления нативной команды очистки.
