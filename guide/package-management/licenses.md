# vp pm licenses {#vp-pm-licenses}

Выводит лицензии, указанные для установленных зависимостей.

```bash
vp pm licenses list
vp pm licenses list --json
```

## Параметры {#options}

`list`, также записываемый как `ls`, — поддерживаемая подкоманда. `--json` запрашивает нативный вывод менеджера пакетов в формате JSON. Vite+ не приводит вывод к общей схеме.

### `list` {#list}

| Параметр | Описание                                   | Примечания                      |
| -------- | ------------------------------------------ | ------------------------------- |
| `--json` | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |

## Совместимость {#compatibility}

### `list` {#list-1}

- **npm:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **pnpm:** 7.17.0 или новее: `pnpm licenses list`. Более ранние версии выводят предупреждение и пропускают выполнение.
- **Yarn Classic:** `yarn licenses list`.
- **Yarn Modern:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Bun:** 1.4.0 или новее: `bun pm licenses`. Более ранние версии выводят предупреждение и пропускают выполнение.

| Параметр | npm | pnpm             | Yarn Classic | Yarn Modern | Bun             | Примечания |
| -------- | --- | ---------------- | ------------ | ----------- | --------------- | ---------- |
| `--json` | Нет | 7.17.0 или новее | Да           | Нет         | 1.4.0 или новее |            |

## Нативные параметры {#native-options}

Например, проект на pnpm может использовать:

```bash
vp pm licenses list -- --prod --long
```

Список нативных параметров: [pnpm licenses](https://pnpm.io/cli/licenses), [Yarn Classic licenses](https://classic.yarnpkg.com/en/docs/cli/licenses) и [Bun pm licenses](https://bun.com/docs/pm/cli/pm). Чтобы передать эти параметры через Vite+, см. [Нативные аргументы](./#native-arguments).
