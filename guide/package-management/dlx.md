# vp dlx {#vp-dlx}

Загружает и запускает пакет, не добавляя его в зависимости проекта.

```bash
vp dlx create-vite my-app
vp dlx --silent create-vite my-app
```

## Параметры {#options}

Параметры Vite+ указываются перед пакетом или командой:

Аргументы после команды передаются выполняемой программе, а не разбираются как параметры Vite+. Режим оболочки интерпретирует синтаксис оболочки; используйте его только с доверенными строками команд.

| Параметр               | Описание                                                                     | Примечания       |
| ---------------------- | ---------------------------------------------------------------------------- | ---------------- |
| `-p, --package <name>` | Делает выбранный пакет доступным выполняемой команде.                        | Можно повторять. |
| `-c, --shell-mode`     | Выполняет команду в среде оболочки.                                          |                  |
| `-s, --silent`         | Подавляет вывод Vite+ и запрашивает нативный тихий вывод, где он доступен.   |                  |

## Совместимость {#compatibility}

- **npm:** `npm exec --yes`.
- **pnpm:** `pnpm dlx`.
- **Yarn Classic:** Запасной вариант: `npx --yes`.
- **Yarn Modern:** `yarn dlx`.
- **Bun:** `bun x`.

| Параметр               | npm | pnpm             | Yarn Classic | Yarn Modern | Bun | Примечания                        |
| ---------------------- | --- | ---------------- | ------------ | ----------- | --- | --------------------------------- |
| `-p, --package <name>` | Да  | Да               | Да           | Да          | Да  |                                   |
| `-c, --shell-mode`     | Да  | 7.21.0 или новее | Да           | Нет         | Нет |                                   |
| `-s, --silent`         | Да  | Да               | Да           | Да          | Да  | Bun подавляет только вывод Vite+. |

Для установленных бинарных файлов проекта используйте `vp exec` или `vpx`. Описание этих сценариев см. в разделе [Запуск бинарных файлов](/guide/vpx).
