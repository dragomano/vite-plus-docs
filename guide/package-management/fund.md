# vp pm fund {#vp-pm-fund}

Показывает информацию о финансировании для установленных зависимостей.

```bash
vp pm fund
vp pm fund --json
```

## Параметры {#options}

| Параметр | Описание                                   | Примечания                      |
| -------- | ------------------------------------------ | ------------------------------- |
| `--json` | Запрашивает нативный вывод в формате JSON. | Вывод сохраняет нативную схему. |

## Совместимость {#compatibility}

- **npm:** `npm fund`.
- **pnpm:** Запасной вариант: `npm fund`.
- **Yarn Classic:** Запасной вариант: `npm fund`.
- **Yarn Modern:** Запасной вариант: `npm fund`.
- **Bun:** Запасной вариант: `npm fund`.

| Параметр | npm | pnpm | Yarn Classic | Yarn Modern | Bun | Примечания |
| -------- | --- | ---- | ------------ | ----------- | --- | ---------- |
| `--json` | Да  | Да   | Да           | Да          | Да  |            |

Bun выводит предупреждение о запасном варианте. Результаты соответствуют представлению npm об установленных зависимостях.
