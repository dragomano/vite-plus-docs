# vp rebuild {#vp-rebuild}

Пересобирает установленные пакеты, например после смены версии Node.js или когда нативному дополнению требуется перекомпиляция. Эта команда верхнего уровня требует глобального CLI. И глобальный CLI, и локальный CLI проекта принимают `vp pm rebuild` и его псевдоним `vp pm rb`.

```bash
vp rebuild
vp rebuild better-sqlite3 sharp
vp rebuild -- --update-binary
```

## Параметры {#options}

Укажите имена пакетов, чтобы пересобрать только их. Опустите их, чтобы запросить полную пересборку. Дополнительных параметров Vite+ нет.

Параметров, специфичных для команды, нет.

## Совместимость {#compatibility}

- **npm:** `npm rebuild`.
- **pnpm:** `pnpm rebuild`.
- **Yarn Classic:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.
- **Yarn Modern:** `yarn rebuild`.
- **Bun:** Команды нет. Выводит предупреждение и завершается успешно, не выполняя операцию.

В pnpm 10 и новее пересборка без указания пакетов учитывает одобрения сценариев сборки. Явное указание пакета обходит это одобрение, поэтому пересобирайте только пакеты, сценариям которых доверяете.

В npm 12 [одобрение сценариев зависимости](./approve-builds) фиксирует политику, но не выполняет сценарии, пропущенные при предыдущей установке. После одобрения пересоберите этот пакет.

## Нативные параметры {#native-options}

Список нативных параметров: [npm rebuild](https://docs.npmjs.com/cli/v11/commands/npm-rebuild), [pnpm rebuild](https://pnpm.io/cli/rebuild) и [Yarn rebuild](https://yarnpkg.com/cli/rebuild). Чтобы передать эти параметры через Vite+, см. [Нативные аргументы](./#native-arguments).
