# vp update {#vp-update}

Обновляет зависимости проекта по правилам обновления выбранного менеджера. Псевдоним: `vp up`.

```bash
vp update
vp update react
vp update --latest
vp update -g
```

## Параметры {#options}

| Параметр                    | Описание                                                                                | Примечания                                                                                |
| --------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `-L, --latest`              | Обновляет до последней версии (игнорирует диапазон semver).                             | Глобальный режим сбрасывает записанные диапазоны версий.                                  |
| `-g, --global`              | Обновляет глобальные пакеты.                                                            | Требуется глобальный CLI. Используется [глобальное хранилище пакетов](./global-packages). |
| `--concurrency <number>`    | Количество параллельных обновлений глобальных пакетов.                                  | Требуется `--global`. Значение должно быть положительным целым числом.                    |
| `--reinstall-node-mismatch` | Переустанавливает актуальные глобальные пакеты, установленные с другой версией Node.js. | Требуется `--global`.                                                                     |
| `--ignore-node-mismatch`    | Пропускает актуальные глобальные пакеты, установленные с другой версией Node.js.        | Требуется `--global`.                                                                     |
| `-r, --recursive`           | Обновляет рекурсивно во всех пакетах рабочего пространства.                             |                                                                                           |
| `--filter <pattern>`        | Выбирает рабочие пространства по шаблону.                                               | Можно указывать несколько раз.                                                            |
| `-w, --workspace-root`      | Включает корень рабочего пространства.                                                  |                                                                                           |
| `-D, --dev`                 | Выбирает зависимости для разработки.                                                    |                                                                                           |
| `-P, --prod`                | Выбирает продакшен-зависимости.                                                         |                                                                                           |
| `-i, --interactive`         | Интерактивный режим.                                                                    |                                                                                           |
| `--no-optional`             | Исключает optionalDependencies.                                                         |                                                                                           |
| `--no-save`                 | Запрашивает нативное поведение без сохранения.                                          |                                                                                           |
| `--workspace`               | Обновляет только зависимости, доступные в рабочем пространстве.                         |                                                                                           |

## Совместимость {#compatibility}

Приведённые ниже команды описывают операции над проектом. Глобальный режим описан в разделе [Параметры](#options).

- **npm:** `npm update`.
- **pnpm:** `pnpm update`.
- **Yarn Classic:** `yarn upgrade` или `yarn upgrade-interactive`.
- **Yarn Modern:** `yarn up`.
- **Bun:** `bun update`.

| Параметр                    | npm                     | pnpm | Yarn Classic | Yarn Modern                  | Bun           | Примечания |
| --------------------------- | ----------------------- | ---- | ------------ | ---------------------------- | ------------- | ---------- |
| `-L, --latest`              | Только глобальный режим | Да   | Да           | Да                           | Да            |            |
| `-g, --global`              | Да                      | Да   | Да           | Да                           | Да            |            |
| `--concurrency <number>`    | Да                      | Да   | Да           | Да                           | Да            |            |
| `--reinstall-node-mismatch` | Да                      | Да   | Да           | Да                           | Да            |            |
| `--ignore-node-mismatch`    | Да                      | Да   | Да           | Да                           | Да            |            |
| `-r, --recursive`           | 8.1.0 или новее         | Да   | Нет          | Да                           | 1.4 или новее |            |
| `--filter <pattern>`        | 7.14.0 или новее        | Да   | Один фильтр  | Нет                          | 1.4 или новее |            |
| `-w, --workspace-root`      | 8.1.0 или новее         | Да   | Нет          | Нет                          | Нет           |            |
| `-D, --dev`                 | Да                      | Да   | Нет          | Нет                          | 1.4 или новее |            |
| `-P, --prod`                | 7 или новее             | Да   | Да           | Нет                          | 1.4 или новее |            |
| `-i, --interactive`         | Нет                     | Да   | Да           | Да                           | Да            |            |
| `--no-optional`             | Да                      | Да   | Да           | Нет                          | 1.4 или новее |            |
| `--no-save`                 | Да                      | Да   | Нет          | `--recursive` без `--latest` | Да            |            |
| `--workspace`               | Нет                     | Да   | Нет          | Нет                          | Нет           |            |

Чтобы изменить объявленный диапазон версий зависимости в npm, используйте [add](./add) с новой спецификацией версии. Yarn Modern следует семантике обновления в масштабе проекта. Рекурсивный режим без `--latest` заново разрешает существующие диапазоны, не переписывая манифесты; в сочетании с `--latest` используется обычный `yarn up`.
