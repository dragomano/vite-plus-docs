# vp outdated {#vp-outdated}

Проверяет, для каких зависимостей доступны более новые версии.

```bash
vp outdated
vp outdated react
vp outdated --format json
vp outdated -g
```

## Параметры {#options}

| Параметр                       | Описание                                             | Примечания                                                                                |
| ------------------------------ | ---------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `--long`                       | Показывает расширенную информацию.                   |                                                                                           |
| `--format <table\|list\|json>` | Выбирает формат вывода.                              |                                                                                           |
| `-r, --recursive`              | Проверяет рекурсивно по всем рабочим пространствам.  |                                                                                           |
| `--filter <pattern>`           | Выбирает рабочие пространства по шаблону.            | Можно указывать несколько раз.                                                            |
| `-w, --workspace-root`         | Включает корень рабочего пространства.               |                                                                                           |
| `-P, --prod`                   | Только продакшен-зависимости и optional-зависимости. |                                                                                           |
| `-D, --dev`                    | Включает зависимости для разработки.                 |                                                                                           |
| `--no-optional`                | Исключает optional-зависимости.                      |                                                                                           |
| `--compatible`                 | Показывает только версии в совместимых диапазонах.   |                                                                                           |
| `--sort-by <field>`            | Сортирует результаты по полю.                        |                                                                                           |
| `-g, --global`                 | Проверяет глобально установленные пакеты.            | Требуется глобальный CLI. Используется [глобальное хранилище пакетов](./global-packages). |
| `--concurrency <number>`       | Количество параллельных проверок глобальных пакетов. | Требуется `--global`. Значение должно быть положительным целым числом.                    |

## Совместимость {#compatibility}

Приведённые ниже команды описывают операции над проектом. Глобальный режим описан в разделе [Параметры](#options).

- **npm:** `npm outdated`.
- **pnpm:** `pnpm outdated`.
- **Yarn Classic:** `yarn outdated`.
- **Yarn Modern:** Альтернатива: `yarn upgrade-interactive`.
- **Bun:** `bun outdated`.

| Параметр                       | npm               | pnpm              | Yarn Classic | Yarn Modern | Bun | Примечания                                                                                      |
| ------------------------------ | ----------------- | ----------------- | ------------ | ----------- | --- | ----------------------------------------------------------------------------------------------- |
| `--long`                       | Да                | Да                | Нет          | Нет         | Нет |                                                                                                 |
| `--format <table\|list\|json>` | table, list, json | table, list, json | table, json  | Нет         | Нет |                                                                                                 |
| `-r, --recursive`              | 7.14.0 или новее  | Да                | Нет          | Нет         | Да  | npm использует `--workspaces` для проверки рабочих пространств, а не транзитивных зависимостей. |
| `--filter <pattern>`           | 7.14.0 или новее  | Да                | Нет          | Нет         | Да  |                                                                                                 |
| `-w, --workspace-root`         | 8.1.0 или новее   | Да                | Нет          | Нет         | Нет |                                                                                                 |
| `-P, --prod`                   | 7 или новее       | Да                | Нет          | Нет         | Да  |                                                                                                 |
| `-D, --dev`                    | Да                | Да                | Нет          | Нет         | Нет |                                                                                                 |
| `--no-optional`                | 7 или новее       | Да                | Нет          | Нет         | Да  |                                                                                                 |
| `--compatible`                 | Нет               | Да                | Нет          | Нет         | Нет |                                                                                                 |
| `--sort-by <field>`            | Нет               | Да                | Нет          | Нет         | Нет |                                                                                                 |
| `-g, --global`                 | Да                | Да                | Да           | Да          | Да  |                                                                                                 |
| `--concurrency <number>`       | Да                | Да                | Да           | Да          | Да  |                                                                                                 |

Yarn Modern не передаёт позиционные имена пакетов. В отличие от запроса outdated только на чтение, его интерактивный инструмент обновления может изменять зависимости.

Нативный вывод и коды возврата различаются. Ненулевой код возврата может указывать на устаревшие зависимости, а не на сбой запроса к реестру.
