# vp why {#vp-why}

Объясняет, почему установлена зависимость. Псевдоним: `vp explain`.

```bash
vp why react
vp why react --json
vp why react --filter web
```

## Параметры {#options}

| Параметр                  | Описание                                                 | Примечания                      |
| ------------------------- | -------------------------------------------------------- | ------------------------------- |
| `--json`                  | Запрашивает нативный вывод в формате JSON.               | Вывод сохраняет нативную схему. |
| `--long`                  | Показывает расширенную информацию.                       |                                 |
| `--parseable`             | Показывает разбираемый вывод.                            |                                 |
| `-r, --recursive`         | Проверяет рекурсивно по всем рабочим пространствам.      |                                 |
| `--filter <pattern>`      | Выбирает рабочие пространства по шаблону.                | Можно указывать несколько раз.  |
| `-w, --workspace-root`    | Проверяет в корне рабочего пространства.                 |                                 |
| `-P, --prod`              | Только продакшен-зависимости.                            |                                 |
| `-D, --dev`               | Только зависимости для разработки.                       |                                 |
| `--depth <depth>`         | Ограничивает глубину дерева.                             |                                 |
| `--no-optional`           | Исключает optional-зависимости.                          |                                 |
| `--exclude-peers`         | Исключает peer-зависимости.                              |                                 |
| `--find-by <finder_name>` | Использует функцию поиска, определённую в .pnpmfile.cjs. |                                 |

## Совместимость {#compatibility}

- **npm:** `npm explain`.
- **pnpm:** `pnpm why`.
- **Yarn Classic:** `yarn why`. С несколькими именами пакетов выводит предупреждение и проверяет только первое.
- **Yarn Modern:** `yarn why`. С несколькими именами пакетов выводит предупреждение и проверяет только первое.
- **Bun:** `bun why`.

| Параметр                  | npm              | pnpm              | Yarn Classic | Yarn Modern | Bun | Примечания                                          |
| ------------------------- | ---------------- | ----------------- | ------------ | ----------- | --- | --------------------------------------------------- |
| `--json`                  | Да               | Да                | Да           | Да          | Нет |                                                     |
| `--long`                  | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `--parseable`             | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `-r, --recursive`         | 7.14.0 или новее | Да                | Нет          | Да          | Нет |                                                     |
| `--filter <pattern>`      | 7.14.0 или новее | Да                | Нет          | Нет         | Нет |                                                     |
| `-w, --workspace-root`    | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `-P, --prod`              | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `-D, --dev`               | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `--depth <depth>`         | Нет              | Да                | Нет          | Нет         | Да  |                                                     |
| `--no-optional`           | Нет              | Да                | Нет          | Нет         | Нет |                                                     |
| `--exclude-peers`         | Нет              | Да                | Нет          | Да          | Нет | Yarn Modern включает peer-зависимости по умолчанию. |
| `--find-by <finder_name>` | Нет              | 10.16.0 или новее | Нет          | Нет         | Нет |                                                     |

Граф зависимостей не включает инструменты, которые Vite+ поставляет в комплекте или компилирует. Чтобы вывод оставался читаемым, Vite+ показывает подсказку, если он также предоставляет запрошенный пакет. Для просмотра встроенных инструментов используйте `vp toolchain [tool]`.
