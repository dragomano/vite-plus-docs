# Удаление Vite+ {#removing-vite}

Используйте `vp implode`, чтобы удалить управляемую Vite+ [глобальную установку `vp`](/guide/global-cli) и связанные с ней пользовательские данные с вашего компьютера. Эта команда не удаляет зависимости `vite-plus` из проектов и пакеты, установленные через Homebrew.

## Обзор {#overview}

`vp implode` — это команда очистки для удаления установленного Vite+ и всех управляемых им данных. Используйте её, если больше не хотите, чтобы Vite+ управлял вашей средой выполнения, менеджером пакетов и связанным состоянием локальных инструментов.

::: info
Если вы решили отказаться от Vite+, пожалуйста, [поделитесь с нами своим отзывом](https://discord.gg/cAnsqHh5PX).
:::

## Использование {#usage}

```bash
vp implode
```

Ознакомьтесь с каталогами и профилями оболочки, которые перечисляет команда, затем введите `boom`, чтобы подтвердить удаление. Любой другой ввод отменяет операцию.

Чтобы пропустить запрос подтверждения, используйте:

```bash
vp implode --yes
```

## Homebrew

Сначала выполните `vp implode`, чтобы удалить управляемые Vite+ среды выполнения, глобальные пакеты, конфигурацию, шимы и записи в настройках оболочки. Затем удалите пакет Homebrew:

```bash
vp implode
brew uninstall vite-plus
```

В запросе подтверждения указано, что пакет Homebrew останется установленным. После очистки `vp implode` предложит выполнить `brew uninstall vite-plus`.

Перезапустите терминал перед повторным запуском `vp`. В Bash вместо этого можно выполнить `hash -r`, чтобы очистить кэшированные пути к командам. Если пакет Homebrew всё ещё установлен, следующая команда `vp` снова запустит первоначальную настройку.
