# Команда `vp fmt` {#format}

`vp fmt` форматирует код с помощью Oxfmt.

## Обзор {#overview}

`vp fmt` основан на [Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html) — форматтере из экосистемы Oxc. Oxfmt полностью совместим с Prettier и разработан как быстрая замена Prettier без необходимости менять рабочие процессы.

Используйте `vp fmt` для форматирования проекта, а `vp check` — для одновременного форматирования, линтинга и проверки типов.

## Использование {#usage}

```bash
vp fmt
vp fmt --check
vp fmt . --write
```

## Конфигурация {#configuration}

Размещайте конфигурацию форматирования непосредственно в блоке `fmt` корневого `vite.config.ts`, чтобы вся конфигурация оставалась в одном месте. Мы не рекомендуем использовать `.oxfmtrc.json` с Vite+.

Если в корневой конфигурации workspace есть блок `fmt`, `vp fmt` и `vp check` используют его даже при запуске из каталога пакета. Конфигурации пакетов не могут заменять корневые настройки форматирования. Команды сохраняют рабочий каталог пакета, поэтому относительные аргументы с путями к файлам сохраняют своё значение. Используйте [`fmt.overrides`](/guide/monorepo#format-overrides) для параметров, специфичных для файла или пакета.

Явный вызов `vp fmt -c <path>` или `vp fmt --config <path>` выбирает другую конфигурацию. В противном случае при запуске из корня workspace или если в корневой конфигурации нет блока `fmt`, Oxfmt находит ближайший файл `vite.config.*` с блоком `fmt`. Поддерживаются расширения `.js`, `.mjs`, `.ts`, `.cjs`, `.mts` и `.cts`. Вложенные конфигурации не переопределяют настройки для отдельных файлов.

Для редакторов отключите вложенные конфигурации форматтера, чтобы предотвратить переопределения для отдельных файлов:

```json [.vscode/settings.json]
{
  "oxc.fmt.disableNestedConfig": true
}
```

Подробное описание поведения форматтера и справочник по его настройке см. в [документации Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html).

```ts [vite.config.ts]
import { defineConfig } from 'vite-plus';

export default defineConfig({
  fmt: {
    singleQuote: true,
  },
});
```
